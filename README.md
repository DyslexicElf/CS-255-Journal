# CS-255-Journal

About the Project
For this portfolio artifact, I put together the core system analysis and design documents for DriverPass, a driver education and licensing management organization. The main goal of this system was to design a comprehensive platform that streamlines everything from student registrations and instructor scheduling to tracking overall lesson progress, keeping students, instructors, and admin staff all on the same page.

What Went Well
I think one of the strongest parts of this project was translating messy, real-world administrative challenges into clean, structured user stories and business requirements. Once those foundational needs were locked down, it made mapping out the overall system architecture and data flow during the design phase feel much more natural and cohesive.

Areas for Growth
If I could go back and revise one part of these documents, I’d definitely dive deeper into the edge cases and error-handling scenarios—like figuring out exact fallback protocols for last-minute lesson cancellations or scheduling overlaps. To improve that next time, I’d include more detailed sequence diagrams specifically mapping out how data stays synced across different user portals when unexpected changes happen.

Why User Needs Matter
To capture the user’s needs accurately, I tried to put myself in the shoes of the actual people using the software every day, breaking down where administrative bottlenecks usually happen. Keeping the end-user front and center is so important because if a system isn't intuitive or practical for students and instructors to actually use, it won't matter how good the backend architecture is—adoption will tank.

My Approach to Software Design
My general approach to design is very requirements-first: I like to figure out the "why" and the "what" before jumping into the technical "how." Moving forward, I plan to keep relying on structured requirements analysis, Agile-friendly component mapping, and iterative diagramming (like UML use cases) to keep projects organized and make sure everyone stays aligned from start to finish.
